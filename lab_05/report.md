# Лабораторная работа №5
## Стохастические методы оптимизации

### Цель работы
Изучение стохастических методов оптимизации для работы с большими данными.

### Теоретические сведения

#### Проблема детерминированных методов
Для задач машинного обучения с функцией потерь:

```
L(w) = (1/n) * Σ l(x_i, y_i, w)
```

Вычисление полного градиента требует O(n) операций, что дорого при больших n.

#### Стохастический градиентный спуск (SGD)
Использует один случайный пример на каждой итерации:

```
w_{k+1} = w_k - α * ∇l(x_i, y_i, w_k),  где i ~ Uniform(1, ..., n)
```

**Преимущества:**
- O(1) сложность на итерацию
- Возможность онлайн-обучения
- Шум помогает избегать локальных минимумов

**Недостатки:**
- Высокая дисперсия градиента
- Медленная сходимость вблизи оптимума

#### Mini-batch градиентный спуск
Компромисс между SGD и полным градиентом:

```
w_{k+1} = w_k - α * (1/|B|) * Σ_{i∈B} ∇l(x_i, y_i, w_k)
```

где B — случайный батч размера batch_size.

**Типичные размеры батча:** 32, 64, 128, 256

#### Стратегии изменения learning rate

**1. Step Decay:**
```
lr = lr_0 * drop_rate^(epoch // epochs_drop)
```

**2. Exponential Decay:**
```
lr = lr_0 * decay_rate^epoch
```

**3. Adaptive Decay:**
```
lr = lr_0 / (1 + decay_rate * epoch)
```

**4. Cosine Annealing:**
```
lr = lr_min + 0.5 * (lr_max - lr_min) * (1 + cos(π * epoch / T_max))
```

### Сравнение методов

| Метод | Сложность/итер | Дисперсия | Сходимость |
|-------|---------------|-----------|------------|
| GD | O(n) | Низкая | Стабильная |
| Mini-batch | O(b) | Средняя | Хорошая |
| SGD | O(1) | Высокая | Шумная |

### Практические рекомендации

1. **Выбор размера батча:**
   - Маленький (16-32): лучше обобщение, больше шума
   - Большой (128-512): стабильнее, быстрее на GPU

2. **Learning rate:**
   - Начните с 0.01 или 0.1
   - Используйте расписание для уменьшения

3. **Перемешивание данных:**
   - Всегда перемешивайте данные перед каждой эпохой
