## Байесовская оптимизация

### Цель работы
Изучение методов оптимизации "чёрных ящиков" и дорогих функций.

### Теоретические сведения

#### Проблема оптимизации "чёрного ящика"
- Функция дорогая для вычисления (обучение нейросети, эксперимент)
- Нет градиента или он шумный
- Нужен баланс exploration/exploitation

#### Гауссовские процессы
Гауссовский процесс — это распределение над функциями:

```
f(x) ~ GP(m(x), k(x, x'))
```

**Предсказание:**
```
μ(x*) = k(x*)^T (K + σ²I)^{-1} y
σ²(x*) = k(x*, x*) - k(x*)^T (K + σ²I)^{-1} k(x*)
```

**RBF ядро:**
```
k(x, x') = σ_f² * exp(-||x - x'||² / (2l²))
```

#### Функции приобретения

**1. Expected Improvement (EI):**
```
EI(x) = E[max(f(x) - y_best - ξ, 0)]
EI(x) = (μ - y_best - ξ) * Φ(z) + σ * φ(z)
где z = (μ - y_best - ξ) / σ
```

**2. Probability of Improvement (PI):**
```
PI(x) = P(f(x) > y_best + ξ) = Φ((μ - y_best - ξ) / σ)
```

**3. Upper Confidence Bound (UCB):**
```
UCB(x) = μ(x) + κ * σ(x)
```

#### Алгоритм байесовской оптимизации
```
1. Инициализация: оценить f в нескольких точках
2. Повторять:
   a. Обучить гауссовский процесс
   b. Найти точку с максимумом функции приобретения
   c. Оценить f в новой точке
   d. Обновить данные
```

### Сравнение функций приобретения

| Функция | Формула | Exploration | Exploitation |
|---------|---------|-------------|--------------|
| EI | (μ-y*)Φ(z) + σφ(z) | Среднее | Среднее |
| PI | Φ((μ-y*)/σ) | Низкое | Высокое |
| UCB | μ + κσ | Высокое (κ>2) | Среднее |

    model = RandomForestClassifier(

        min_samples_leaf=int(min_samples)

    return -cross_val_score(model, X, y, cv=5).mean()
