# Лабораторная работа №1
## Градиентные методы первого порядка

### Цель работы
Изучение основных понятий оптимизации, реализация метода градиентного спуска с постоянным и адаптивным шагом.

### Теоретические сведения

**Градиентный спуск** — итерационный метод оптимизации первого порядка для нахождения локального минимума функции.

Основная идея: двигаться в направлении, противоположном градиенту функции:

```
x_{k+1} = x_k - α * ∇f(x_k)
```

где:
- `α` — размер шага (learning rate)
- `∇f(x_k)` — градиент функции в точке `x_k`

**Метод с постоянным шагом:** использует фиксированный размер шага на всех итерациях.

**Метод с адаптивным шагом (backtracking line search):** автоматически подбирает размер шага на каждой итерации, используя условие Армихо:

```
f(x - t*∇f(x)) ≤ f(x) - α * t * ||∇f(x)||²
```
