# Лабораторная работа №3
## Методы второго порядка

### Цель работы
Изучение методов оптимизации, использующих информацию о вторых производных (матрице Гессе).

### Теоретические сведения

#### Матрица Гессе
Матрица вторых частных производных:

```
H_ij = ∂²f / (∂x_i ∂x_j)
```

#### Метод Ньютона
Использует квадратичную аппроксимацию функции:

```
x_{k+1} = x_k - H^{-1}(x_k) * ∇f(x_k)
```

**Преимущества:**
- Квадратичная сходимость вблизи минимума
- Учитывает кривизну функции

**Недостатки:**
- Требует вычисления матрицы Гессе O(n²)
- Требует обращения матрицы O(n³)
- Может расходиться при плохом начальном приближении

#### Модифицированный метод Ньютона
Добавляет регуляризацию для обеспечения положительной определённости:

```
x_{k+1} = x_k - (H + λI)^{-1} * ∇f(x_k)
```

#### Квазиньютоновские методы
Аппроксимируют матрицу Гессе или обратную к ней, используя только градиенты.

**BFGS (Broyden-Fletcher-Goldfarb-Shanno):**

Обновление обратной матрицы Гессе:

```
H_{k+1} = (I - ρ_k * s_k * y_k^T) * H_k * (I - ρ_k * y_k * s_k^T) + ρ_k * s_k * s_k^T
```

где:
- s_k = x_{k+1} - x_k
- y_k = ∇f(x_{k+1}) - ∇f(x_k)
- ρ_k = 1 / (y_k^T * s_k)

**L-BFGS (Limited-memory BFGS):**
- Хранит только последние m пар (s_k, y_k)
- Эффективен для задач большой размерности
- Не хранит матрицу явно
