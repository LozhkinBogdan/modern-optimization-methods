# План лабораторных работ
## по дисциплине "Современные методы оптимизации"
### Язык реализации: Python

---

## Общая информация

**Количество лабораторных работ:** 8

**Цель курса:** Изучение классических и современных методов оптимизации, приобретение практических навыков реализации и применения оптимизационных алгоритмов на языке Python.

**Необходимые библиотеки:**
- `numpy` — численные вычисления
- `scipy` — научные вычисления и оптимизация
- `matplotlib` — визуализация
- `pandas` — работа с данными (опционально)

---

## Перечень лабораторных работ

### Лабораторная работа №1
**Тема:** Введение в оптимизацию. Градиентные методы первого порядка

**Цель:** Изучение основных понятий оптимизации, реализация метода градиентного спуска.

**Задания:**
1. Реализовать функцию вычисления градиента для многомерных функций
2. Реализовать метод градиентного спуска с постоянным шагом
3. Реализовать метод градиентного спуска с адаптивным шагом
4. Провести сравнительный анализ на тестовых функциях (сфера, Розенброка, Растригина)

**Ожидаемый результат:** Работающий код с визуализацией сходимости методов.

---

### Лабораторная работа №2
**Тема:** Методы ускорения градиентного спуска

**Цель:** Изучение современных модификаций градиентного спуска.

**Задания:**
1. Реализовать метод Momentum (градиентный спуск с инерцией)
2. Реализовать метод Nesterov Accelerated Gradient
3. Реализовать метод AdaGrad
4. Реализовать метод Adam
5. Сравнить эффективность на различных функциях потерь

**Ожидаемый результат:** Сравнительная таблица сходимости методов, графики обучения.

---

### Лабораторная работа №3
**Тема:** Методы второго порядка. Метод Ньютона

**Цель:** Изучение методов оптимизации, использующих информацию о вторых производных.

**Задания:**
1. Реализовать вычисление матрицы Гессе
2. Реализовать классический метод Ньютона
3. Реализовать модифицированный метод Ньютона с регуляризацией
4. Реализовать квазиньютоновские методы (BFGS, L-BFGS)
5. Сравнить с методами первого порядка

**Ожидаемый результат:** Анализ преимуществ и недостатков методов второго порядка.

---

### Лабораторная работа №4
**Тема:** Методы условной оптимизации

**Цель:** Изучение методов решения задач с ограничениями.

**Задания:**
1. Реализовать метод проекции градиента
2. Реализовать метод штрафных функций
3. Реализовать метод барьерных функций
4. Реализовать метод множителей Лагранжа
5. Решить задачу оптимизации с ограничениями-равенствами и неравенствами

**Ожидаемый результат:** Решение практических задач с ограничениями.

---

### Лабораторная работа №5
**Тема:** Стохастические методы оптимизации

**Цель:** Изучение методов для оптимизации больших данных и негладких функций.

**Задания:**
1. Реализовать стохастический градиентный спуск (SGD)
2. Реализовать Mini-batch градиентный спуск
3. Исследовать влияние размера батча на сходимость
4. Реализовать SGD с различными стратегиями изменения learning rate

**Ожидаемый результат:** Анализ эффективности стохастических методов на больших наборах данных.

---

### Лабораторная работа №6
**Тема:** Методы глобальной оптимизации

**Цель:** Изучение методов поиска глобального экстремума многоэкстремальных функций.

**Задания:**
1. Реализовать метод случайного поиска
2. Реализовать метод имитации отжига (Simulated Annealing)
3. Реализовать генетический алгоритм
4. Реализовать метод роя частиц (Particle Swarm Optimization)
5. Сравнить на многоэкстремальных функциях

**Ожидаемый результат:** Сравнение способности методов избегать локальных экстремумов.

---

### Лабораторная работа №7
**Тема:** Байесовская оптимизация

**Цель:** Изучение методов оптимизации "чёрных ящиков" и дорогих функций.

**Задания:**
1. Изучить основы гауссовских процессов
2. Реализовать функцию приобретения (Acquisition Function): EI, PI, UCB
3. Реализовать базовый алгоритм байесовской оптимизации
4. Применить для оптимизации гиперпараметров модели машинного обучения

**Ожидаемый результат:** Оптимизация гиперпараметров модели ML с минимальным числом итераций.

---

### Лабораторная работа №8
**Тема:** Применение методов оптимизации в машинном обучении

**Цель:** Закрепление навыков применения оптимизационных методов для решения практических задач ML.

**Задания:**
1. Реализовать линейную регрессию с использованием различных методов оптимизации
2. Реализовать логистическую регрессию
3. Реализовать обучение нейронной сети (минимум 1 скрытый слой)
4. Сравнить эффективность различных оптимизаторов на реальных данных

**Ожидаемый результат:** Работающие модели машинного обучения с различными оптимизаторами.
