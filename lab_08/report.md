# Лабораторная работа №8
## Применение методов оптимизации в машинном обучении

### Цель работы
Закрепление навыков применения оптимизационных методов для решения практических задач машинного обучения.

### Теоретические сведения

#### 1. Линейная регрессия
**Модель:**
```
y = Xw + b
```

**Функция потерь (MSE):**
```
L(w, b) = (1/2n) * ||Xw + b - y||²
```

**Градиенты:**
```
∂L/∂w = X^T(Xw + b - y) / n
∂L/∂b = mean(Xw + b - y)
```

#### 2. Логистическая регрессия
**Модель:**
```
p(y=1|x) = σ(Xw + b)
```

**Функция потерь (Binary Cross-Entropy):**
```
L(w, b) = -mean(y*log(p) + (1-y)*log(1-p))
```

**Градиенты:**
```
∂L/∂w = X^T(p - y) / n
∂L/∂b = mean(p - y)
```

#### 3. Нейронная сеть
**Архитектура:**
```
Input (n_features) -> Hidden (n_hidden, ReLU) -> Output (1, sigmoid)
```

**Прямой проход:**
```
z1 = X * W1 + b1
a1 = ReLU(z1)
z2 = a1 * W2 + b2
a2 = sigmoid(z2)
```

**Обратный проход (Backpropagation):**
```
dz2 = a2 - y
dW2 = a1^T * dz2 / n
db2 = mean(dz2)

da1 = dz2 * W2^T
dz1 = da1 ⊙ ReLU'(z1)
dW1 = X^T * dz1 / n
db1 = mean(dz1)
```

### Метрики качества

**Регрессия:**
- R² (коэффициент детерминации): `1 - SS_res / SS_tot`
- MSE: `mean((y - y_pred)²)`

**Классификация:**
- Accuracy: `mean(y_pred == y)`
- Precision, Recall, F1-score
