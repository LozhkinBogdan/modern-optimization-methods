# Современные методы оптимизации

Репозиторий содержит лабораторные работы по дисциплине "Современные методы оптимизации".

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Структура проекта

```
SMO/
├── lab_01/          # Градиентные методы первого порядка
├── lab_02/          # Методы ускорения градиентного спуска
├── lab_03/          # Методы второго порядка
├── lab_04/          # Условная оптимизация
├── lab_05/          # Стохастические методы
├── lab_06/          # Глобальная оптимизация
├── lab_07/          # Байесовская оптимизация
├── lab_08/          # Применение в машинном обучении
├── utils/           # Общие утилиты
├── requirements.txt
└── README.md
```

## Запуск лабораторных работ

Каждая лабораторная работа находится в отдельной папке. Для запуска:

```bash
cd lab_01
python main.py
```

## Содержание

| № | Тема |
|---|------|
| 1 | Градиентные методы первого порядка |
| 2 | Методы ускорения (Momentum, Adam, AdaGrad) |
| 3 | Методы второго порядка (Ньютон, BFGS) |
| 4 | Условная оптимизация (ограничения) |
| 5 | Стохастические методы (SGD, Mini-batch) |
| 6 | Глобальная оптимизация |
| 7 | Байесовская оптимизация |
| 8 | Применение в машинном обучении |

## Требования

- Python 3.8+
- numpy, scipy, matplotlib, pandas
