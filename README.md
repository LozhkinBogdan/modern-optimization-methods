---

## 📋 О курсе

**Цель курса:** Изучение классических и современных методов оптимизации, приобретение практических навыков реализации и применения оптимизационных алгоритмов на языке Python.

**Количество лабораторных работ:** 8

pip install -r requirements.txt

## 📚 Содержание лабораторных работ

| № | Тема | Ключевые алгоритмы |
|---|------|-------------------|
| 1 | **Градиентные методы первого порядка** | Градиентный спуск (постоянный/адаптивный шаг) |
| 2 | **Методы ускорения** | Momentum, Nesterov, AdaGrad, Adam |
| 3 | **Методы второго порядка** | Ньютон, BFGS, L-BFGS, вычисление Гессе |
| 4 | **Условная оптимизация** | Проекция градиента, штрафные функции, барьерные функции, Лагранж |
| 5 | **Стохастические методы** | SGD, Mini-batch, стратегии learning rate |
| 6 | **Глобальная оптимизация** | Случайный поиск, имитация отжига, генетический алгоритм, рой частиц |
| 7 | **Байесовская оптимизация** | Гауссовские процессы, EI, PI, UCB |
| 8 | **Применение в ML** | Линейная/логистическая регрессия, нейронные сети |

## 🏃 Запуск лабораторных работ

Каждая лабораторная работа находится в отдельной папке. Для запуска:

```bash
cd lab_01
python main.py
```

### Пример запуска всех работ

```bash
# Лабораторная 1: Градиентный спуск
cd lab_01 && python main.py

# Лабораторная 2: Ускоренные методы
cd lab_02 && python main.py

# ... и так далее
```
