# Лабораторная работа №6
## Методы глобальной оптимизации

### Цель работы
Изучение методов поиска глобального экстремума многоэкстремальных функций.

### Теоретические сведения

#### Проблема глобальной оптимизации
Градиентные методы находят только локальный минимум. Для многоэкстремальных функций требуется использование специальных методов.

#### 1. Метод случайного поиска
Простейший метод, исследующий пространство случайным образом.

**Алгоритм:**
1. Генерировать случайные точки в области поиска
2. Запоминать лучшую
3. Сужать область вокруг лучшей точки

#### 2. Метод имитации отжига (Simulated Annealing)
Вдохновлён процессом отжига в металлургии.

**Алгоритм:**
```
1. Начать с высокой температуры T
2. Предложить новое решение
3. Принять лучшее всегда
4. Принять худшее с вероятностью exp(-ΔE/T)
5. Уменьшить температуру
```

**Вероятность принятия худшего решения:**
```
P(accept) = exp(-Δf / T), если Δf > 0
```

#### 3. Генетический алгоритм
Эволюционный метод, основанный на естественном отборе.

**Операторы:**
- **Селекция:** выбор лучших особей (турнирная, рулетка)
- **Кроссовер:** скрещивание родителей
- **Мутация:** случайные изменения
- **Элитизм:** сохранение лучших

#### 4. Метод роя частиц (PSO)
Моделирует поведение стаи птиц или косяка рыб.

**Обновление частицы:**
```
v_{k+1} = w * v_k + c1 * r1 * (pbest - x_k) + c2 * r2 * (gbest - x_k)
x_{k+1} = x_k + v_{k+1}
```

где:
- `pbest` — лучшая позиция частицы
- `gbest` — лучшая позиция роя
- `w` — инерция
- `c1, c2` — коэффициенты обучения

### Сравнение методов

| Метод | Параметры | Преимущества | Недостатки |
|-------|-----------|--------------|------------|
| Random Search | min | Простота | Медленная сходимость |
| Simulated Annealing | T0, alpha | Теоретическая сходимость | Чувствителен к параметрам |
| Genetic Algorithm | pop_size, mutation | Глобальный поиск | Много вычислений |
| PSO | n_particles, w, c1, c2 | Быстрая сходимость | Может застрять |
