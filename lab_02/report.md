# Лабораторная работа №2
## Методы ускорения градиентного спуска

### Цель работы
Изучение современных модификаций градиентного спуска для ускорения сходимости.

### Теоретические сведения

#### 1. Momentum (Инерция)
Добавляет "инерцию" к обновлениям, накапливая предыдущие градиенты:

```
v_{k+1} = β * v_k + α * ∇f(x_k)
x_{k+1} = x_k - v_{k+1}
```

**Преимущества:**
- Ускорение в направлениях с постоянной кривизной
- Подавление осцилляций

#### 2. Nesterov Accelerated Gradient (NAG)
Улучшенная версия Momentum с "заглядыванием вперёд":

```
x_ahead = x_k - β * v_k
v_{k+1} = β * v_k + α * ∇f(x_ahead)
x_{k+1} = x_k - v_{k+1}
```

#### 3. AdaGrad (Adaptive Gradient)
Адаптивно изменяет learning rate для каждого параметра:

```
G_{k+1} = G_k + (∇f(x_k))²
x_{k+1} = x_k - α * ∇f(x_k) / (√G_{k+1} + ε)
```

**Преимущества:**
- Хорошо работает с разреженными градиентами
- Не требует ручного подбора learning rate

**Недостатки:**
- Learning rate может стать слишком маленьким

#### 4. RMSprop
Модификация AdaGrad с экспоненциальным затуханием:

```
E[g²]_{k+1} = β * E[g²]_k + (1-β) * (∇f(x_k))²
x_{k+1} = x_k - α * ∇f(x_k) / (√E[g²]_{k+1} + ε)
```

#### 5. Adam (Adaptive Moment Estimation)
Комбинирует Momentum и RMSprop:

```
m_{k+1} = β₁ * m_k + (1-β₁) * ∇f(x_k)           # первый момент
v_{k+1} = β₂ * v_k + (1-β₂) * (∇f(x_k))²        # второй момент
m̂ = m_{k+1} / (1 - β₁^{k+1})                     # коррекция смещения
v̂ = v_{k+1} / (1 - β₂^{k+1})
x_{k+1} = x_k - α * m̂ / (√v̂ + ε)
```

**Параметры по умолчанию:**
- α = 0.001
- β₁ = 0.9
- β₂ = 0.999
- ε = 1e-8
