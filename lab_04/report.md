# Лабораторная работа №4
## Методы условной оптимизации

### Цель работы
Изучение методов решения задач оптимизации с ограничениями.

### Теоретические сведения

#### Задача условной оптимизации
```
minimize f(x)
subject to:
    g_i(x) ≤ 0,  i = 1, ..., m  (неравенства)
    h_j(x) = 0,  j = 1, ..., p  (равенства)
    x ∈ X                       (множество допустимых решений)
```

#### 1. Метод проекции градиента
Для задач с ограничениями-коробкой или простыми множествами:

```
x_{k+1} = P_X(x_k - α * ∇f(x_k))
```

где P_X — оператор проекции на множество X.

**Проекции:**
- На коробку [l, u]: `P(x)_i = clip(x_i, l_i, u_i)`
- На симплекс: алгоритм сортировки

#### 2. Метод штрафных функций
Преобразует задачу с ограничениями в последовательность задач без ограничений:

```
minimize f(x) + μ * Σ max(0, g_i(x))²
```

**Алгоритм:**
1. Начать с малого μ
2. Минимизировать функцию с штрафом
3. Увеличить μ
4. Повторять до сходимости

#### 3. Метод барьерных функций
Для задач с неравенствами, требует строго допустимой начальной точки:

```
minimize f(x) - μ * Σ log(-g_i(x))
```

**Особенности:**
- Работает только внутри допустимой области
- μ уменьшается к 0

#### 4. Метод множителей Лагранжа
Для задач с ограничениями-равенствами:

```
L(x, λ) = f(x) + Σ λ_j * h_j(x)
```

**Расширенный Лагранжиан:**
```
L_A(x, λ, μ) = f(x) + Σ λ_j*h_j(x) + (μ/2)*Σh_j(x)²
```

2. ✅ Реализовать метод штрафных функций
3. ✅ Реализовать метод барьерных функций
4. ✅ Реализовать метод множителей Лагранжа
5. ✅ Решить задачу с ограничениями-равенствами и неравенствами

### Типы ограничений

| Тип | Формат | Метод решения |
|-----|--------|---------------|
| Коробка | l ≤ x ≤ u | Проекция градиента |
| Неравенства | g(x) ≤ 0 | Штрафные/барьерные функции |
| Равенства | h(x) = 0 | Множители Лагранжа |
| Смешанные | g(x) ≤ 0, h(x) = 0 | Расширенный Лагранжиан |
